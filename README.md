# Hello Python

A simple Python project that demonstrates basic counting operations.

## Project Description

This project contains a Python script that counts up from 1 to 1002, then counts down from 1002 back to 1. It's a straightforward example of loops and sequential programming in Python.

## Files

- `count.py` - The main Python script containing the counting functionality

## Requirements

- Python 3.x

## Usage

To run the program, execute the following command:

```bash
python3 count.py
```

The script will:
1. Count up from 1 to 1002
2. Display a blank line
3. Count down from 1002 to 1
4. Print "Done!" when complete

## Example Output

```
Counting up to 1003...
1
2
3
...
1002

Counting down from 1002...
1002
1001
...
1
Done!
```

## Installation

No special installation is required. Simply ensure you have Python 3 installed on your system.
